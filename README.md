# Автоматическая нарезка видео в терминале

Этот скрипт позволяет легко и быстро нарезать видеофайлы на несколько частей, а также выбрать формат для каждого файла. Все операции происходят автоматически, и вам нужно только следовать простым инструкциям на экране.

## Что делает скрипт:

- Ищет видеофайлы с расширениями `mp4`, `mkv`, `avi`, `mov`, `flv` в текущей директории.
- Показывает длительность каждого найденного видео.
- Позволяет выбрать видеофайл для нарезки.
- Дает возможность выбрать количество частей, на которое нужно разделить видео.
- Предлагает выбор формата для нарезанных файлов, поддерживаются следующие форматы: `mp4`, `mkv`, `avi`, `mov`, `flv`.
- Создает папку для сохранения нарезанных частей, именуя их по порядку.

## Установка и запуск:

1. Сохраните скрипт в файл с именем `videos`.
2. Просто запустите его двойным кликом, и скрипт начнёт выполнение.

## Как использовать:

1. После запуска скрипт автоматически находит все видеофайлы в текущей директории и выводит их список на экран.
2. Выберите видео, которое хотите нарезать, введя его номер.
3. Укажите количество частей, на которое нужно разделить видео.
4. Выберите формат для нарезанных файлов из предложенного списка (например, `mp4`, `mkv`, `avi`, `mov`, `flv`).
5. Нарезанные части будут сохранены в папке `videos/имя_видео/`, где `имя_видео` — это имя исходного видеофайла.

## Пример работы:

1. Скрипт находит все видеофайлы в текущей директории и показывает их длительность.
2. Вам предлагается выбрать видео из списка.
3. Затем вы вводите количество частей для нарезки.
4. После этого выбираете нужный формат для нарезанных частей.
5. Скрипт выполнит нарезку и сохранит файлы в папке, названной по имени исходного видео.

## Итог:

Этот скрипт упрощает процесс нарезки видео, избавляя вас от необходимости вручную вводить команды в `ffmpeg`. Он автоматически находит видео, позволяет выбрать параметры нарезки и сохраняет файлы в нужном формате. Всё, что вам нужно — это просто запустить его, выбрать параметры и дождаться завершения.
